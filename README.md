## Getting started

```bash
git clone https://github.com/radhe-8075/class_practise.git
cd class_practise
```

Open the project in a Java IDE, configure a suitable JDK, and run an individual exercise from `src/`. Programs are separate learning examples; this repository is not a single application.

**Entry points:** some exercises use `static void main(String[] args)` without `public`. If your JDK or IDE does not recognize that entry point, change it locally to `public static void main(String[] args)`.

For example, after applying that compatibility change to [Sum_of_digit.java](src/Assignment1/Sum_of_digit.java):

```bash
javac -d out src/Assignment1/Sum_of_digit.java
java -cp out Assignment1.Sum_of_digit
```

Enter a number when prompted for input, for example `123`; its digit sum is `6`.

## Learning focus

- Writing and tracing loops and conditionals.
- Working with arrays, strings and user input.
- Breaking problems into smaller steps.
- Practicing classes, interfaces and object-oriented concepts.
- Checking input assumptions and edge cases.

These are coursework and practice solutions, with varying levels of completeness and optimization.
